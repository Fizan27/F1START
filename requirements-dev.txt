# What the TRAINING MACHINE needs (Windows, NVIDIA RTX 50 series GPU).
#
# Install in two steps, because the GPU build of PyTorch lives on PyTorch's
# own package index. RTX 50 series cards need a build for CUDA 12.8 or newer
# (cu128, cu130, ...); older builds install but cannot run on the card.
#
#   .venv\Scripts\python.exe -m pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cu130
#   .venv\Scripts\python.exe -m pip install -r requirements-dev.txt
#
# Do NOT install requirements.txt on this machine: it would replace the GPU
# build of PyTorch with the CPU one.
