# Archive: the F1 race strategy simulator

This folder holds the project this repository used to contain: an F1 race
strategy simulator with a PPO strategist and a Streamlit app. It was finished
on 2026-10-09 and then replaced by F1-EQUALIZER (see the README in the top
folder).

Nothing here is used by the new project, and nothing outside this folder
imports from it. It is kept so the work and its results are not lost.

- `README_strategy_simulator.md`: the old README, with its results.
- `docs/`: the old decisions log, map and interview guide.
- `models/`, `results/`, `app_data/`: the trained models and measured results.

The code expected to run from the top folder, next to `data/`. To run it
again, copy the files back to the top folder of a checkout of commit `09589ad`.
